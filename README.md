# LipatoS - Mastercrafted

Система крафта для **Foundry Virtual Tabletop 14**, основанная на Mastercrafted от **theripper93**.

## Версия

**6.0.3-lipatos.1**

## Совместимость

- Foundry VTT: **14**
- Модуль в целом системонезависимый.
- Для D&D 5e сохранена встроенная интеграция проверок навыков, характеристик и инструментов; используемые API совместимы с **D&D5e 6.0.5**.

## Возможности

- создание книг рецептов и отдельных рецептов;
- ингредиенты с количеством, тегами и альтернативными компонентами;
- выдача созданных предметов персонажу;
- расход компонентов и ресурсов при крафте;
- проверки характеристик, навыков и инструментов в D&D5e;
- настройка сложности проверки и модификаторов результата;
- время крафта и отложенное изготовление;
- отдельное приложение «Котёл»;
- интеграция с Item Piles через контекстное меню;
- просмотр ингредиентов и продуктов игроками с сохранённым исправлением текущей рабочей сборки.

## Важно об ID

Внутренний ID **`mastercrafted` сохранён без изменений**. Это нужно для существующих настроек мира, флагов документов, шаблонов, API и путей ресурсов.

Оригинальный Mastercrafted и эту сборку одновременно устанавливать не нужно.

## Внутренний ID

Пакет LipatoS использует собственный ID `lipatos-mastercrafted`. Это сделано специально: оригинальный ID зарегистрирован в каталоге Foundry как защищённый пакет, из-за чего Foundry пыталась запрашивать авторизацию даже для нашей GitHub-сборки.

Старые флаги и данные журналов сохранены в прежних пространствах имён для совместимости мира.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте:

`https://github.com/Lipatosha/LipatoS-mastercrafted/releases/latest/download/module.json`
