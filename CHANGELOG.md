# История изменений

## 6.0.3-lipatos.1

- Внутренний ID пакета изменён на `lipatos-mastercrafted`, чтобы Foundry больше не связывала сборку LipatoS с защищённым пакетом из официального каталога.
- Путь загрузки переведён на GitHub Releases.
- Пути ресурсов внутри модуля обновлены под новый ID.
- Данные мира и старые флаги сохранены для совместимости.

## 6.0.2-player-inspection-fix

- Текущая рабочая сборка перенесена в линейку **LipatoS**.
- Видимое название изменено на **LipatoS - Mastercrafted**.
- Внутренний ID `mastercrafted` сохранён для совместимости.
- Сохранено исправление просмотра ингредиентов и продуктов игроками из предоставленной рабочей версии.
- Сохранена совместимость с Foundry VTT 14.
- Проверены используемые D&D5e API для версии **6.0.5**; дополнительная смена ID или структуры данных не требуется.
- Добавлены ссылки на репозиторий, манифест, установочный архив и issue tracker LipatoS.
- Сохранена информация об оригинальном авторе **theripper93**.
